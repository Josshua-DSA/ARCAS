ARCAS API

A REST API over news sentiment and market prices for three locked macro targets. Every number is computed deterministically; no generative model sits in the inference path.

Quickstart

Run the service locally. Python 3.11 or newer.

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn backend.src.serve.app:create_app --factory --port 8000

Then confirm it is alive:

curl -s http://localhost:8000/health
# {"status":"ok","version":"0.5.0","universe_count":3}

The interactive schema browser lives at /docs on the same host. It is generated by FastAPI from the live route definitions, so it always matches the running build.

Endpoints

Eleven routes. All are GET except POST /api/simulate.

MethodPathReturns
GET/healthLiveness, version, universe count
GET/api/metaProvenance: versions, coverage, freshness
GET/api/universeMetadata for the three locked targets
GET/api/series/{target}Paired daily sentiment and price series
GET/api/impacts/{target}Recent article impacts with time audit fields
GET/api/stats/{target}Econometric results; Spearman recomputed when max_lag is set
GET/api/allocationAllocation tilt across five asset classes
GET/api/persona/{article_id}Five persona stances for one article
POST/api/simulateScore, direction, and stances for one news text
GET/api/simulate/{run_id}Stored simulation trace, not a recomputation
GET/api/preload/statusLast news preload run and its outcome

Parameters worth knowing

  • target — one of XAU, RATE_UST, SPX. Anything else returns 404.
  • limit on /api/impacts — default 50, maximum 200.
  • max_lag on /api/stats — 0 to 10. Omit it to read stored results.
  • start_date / end_date on /api/series — ISO dates; default is the last 90 days.

Examples

Read provenance before trusting a number

curl -s http://localhost:8000/api/meta | jq '.coverage'

coverage carries articles, days_with_news, and the last price and news dates. If mode is empty, the database has no data yet and the interface hides its figures rather than inventing them.

Pull a price and sentiment series

curl -s "http://localhost:8000/api/series/XAU?start_date=2026-08-01"

Returns sentiments and prices as separate arrays. A day with no news is absent from sentiments — it is never zero, because zero means neutral sentiment, which is a different claim.

Score one news text

curl -s -X POST http://localhost:8000/api/simulate \
  -H "Content-Type: application/json" \
  -d '{"text":"Gold steadies as the dollar retreats from a two-week high","kind":"berita"}'

kind is required and never guessed. Only news or rumour is accepted; questions and conversation are rejected with 422 and an explanation, rather than answered with a number.

Design rules

These are architectural constraints, not style preferences. They are enforced by tests.

  • Three targets, locked. XAU, RATE_UST, SPX. No oil, copper, gas, crypto, or index additions.
  • No generative model in the inference path. The NLP model reads text and emits three-class probabilities. Every aggregation, score, and statistic is deterministic.
  • Allocation always totals 100.0% across five classes: bond, mutual fund, stock, ETF, gold.
  • No lookahead. Models are frozen; new data is only inferred. No online retraining. Daily cut-off is 00:00 UTC.
  • article_id is SHA-256 of normalised text. It is never reassigned.
  • A day without news is NULL, not zero.
