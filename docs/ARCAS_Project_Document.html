Python FastAPI Financial Sentiment Market Analytics

1. Ringkasan Proyek

ARCAS adalah sistem analitik kuantitatif deterministik yang membaca berita keuangan makro, menilai sentimen teks, lalu menghubungkan dampak sentimen tersebut ke 3 target makro terkunci (XAU, RATE_UST, SPX). Tujuannya bukan untuk memprediksi harga secara langsung, melainkan untuk mengukur asosiasi statistik antara sentimen berita dan pergerakan pasar.

Proyek ini fokus pada sentimen berita dalam Bahasa Indonesia dan Inggris, klasifikasi 3 kelas (positif, netral, negatif), pemetaan dampak ke aset tertentu, serta analisis statistik yang deterministik. Sistem ini membangun konteks pasar yang dapat dijelaskan, terukur, dan dibenarkan secara data.

Intinya: proyek ini menghubungkan data tekstual (berita) dengan data pasar (harga, indeks, komoditas, FX, dan volatilitas) dengan cara yang transparent, explainable, dan tidak bergantung pada agen generatif di jalur utama.

2. Masalah yang Diselesaikan

  • Berita keuangan sering kali berisi informasi yang relevan, tetapi tidak semua berita berdampak sama.
  • Satu berita dapat memengaruhi emas, dolar, indeks, dan market risk sekaligus.
  • Sering kali dampak tidak langsung, tidak jelas, atau terlalu ambigu.
  • Tim membutuhkan sistem yang mampu membaca berita secara otomatis, mengaitkan aset, menilai arah dampak, dan mengukur signifikansi statistiknya.

3. Domain Knowledge Penting

3.1 Tone vs Direction

Dalam proyek ini, ada perbedaan penting antara tone dan direction:

  • Tone: sentimen teks (positive, neutral, negative)
  • Direction: dampak terhadap target aset (bullish, bearish, neutral, mixed)

Contoh: kalimat “USD menguat akibat data inflasi AS yang kuat” memiliki tone positif, tetapi terhadap emas, direction bisa bersifat bearish karena USD yang kuat biasanya negatif bagi harga emas.

3.2 Asosiasi Statistik, Bukan Prediksi Harga

ARCAS tidak menargetkan prediksi harga secara langsung. Sistem ini mengukur apakah sentimen berita berkorelasi atau mendahului pergerakan pasar. Dengan demikian, output sistem lebih dekat ke analisis market association daripada sinyal trading otomatis.

4. Arsitektur Sistem

Proyek ini dibagi dalam 3 lapisan utama.

4.1 Lapisan 1 — Data Ingestion & Storage

  • mengambil berita dari berbagai sumber dan API/RSS;
  • mengambil data harga pasar dari yfinance atau sumber yang setara;
  • menyimpan hasil ke SQLite dan Parquet;
  • menjaga konsistensi dan kualitas data.

4.2 Lapisan 2 — NLP dan Engine Analitik

  • membersihkan teks;
  • mendeteksi bahasa dan timezone;
  • menseleksi aset target yang relevan;
  • menilai sentimen teks;
  • menghitung agregasi harian;
  • mengukur hubungan dengan return dan market movement.

4.3 Lapisan 3 — Presentation Layer

  • REST API FastAPI;
  • dashboard web statis (Vanilla JS + ECharts);
  • terminal dashboard berbasis Python Rich.

5. Alur Kerja Sistem

  1. Ambil berita dan harga pasar
  2. Bersihkan dan standarkan data
  3. Deteksi bahasa dan waktu efektif pasar
  4. Pemetaan berita ke aset target
  5. Menilai sentimen teks
  6. Menentukan arah dampak terhadap target aset
  7. Mengagregasi hasil per hari
  8. Menguji hubungan dengan harga dan return
  9. Menyusun rekomendasi portofolio dan stance investor
  10. Menyajikan hasil ke API dan dashboard

7. Penjelasan Komponen Utama

7.1 context/

Folder ini adalah fondasi dokumentasi proyek:

  • PRD.md — ringkasan produk dan kebutuhan bisnis
  • ARCHITECTURE.md — arsitektur sistem
  • DESIGN.md — model dan statistik
  • SCHEMA.md — struktur data dan kontrak
  • RULES.md — aturan yang wajib diikuti tim

7.2 backend/src/schema.py

File ini berisi kontrak data utama dalam bentuk Pydantic v2. Model-model seperti RawArticle, Article, TargetTag, ModelProbs, TargetImpact, DailySentiment, dan AllocationSuggestion menjadi jantung integritas data.

Contoh aturan penting: hari tanpa berita tidak boleh diubah menjadi 0; total alokasi harus selalu 100%; setiap model output harus konsisten secara validasi.

7.3 backend/src/serve/app.py

File ini mendefinisikan REST API untuk sistem. Beberapa endpoint yang sudah ada mencakup:

  • /health
  • /api/universe
  • /api/series/{target}
  • /api/impacts/{target}
  • /api/stats/{target}
  • /api/allocation
  • /api/persona/{article_id}

7.4 data/impact_graph.yaml

File ini mendefinisikan hubungan tema makro dengan aset. Contoh: suku bunga naik, inflasi naik, USD menguat, geopolitik, dan risk-off semuanya dipetakan ke target relevan.

7.5 data/personas.yaml

File ini mendefinisikan lima profil investor: Retail, Day Trader, Fund Manager, Pension, dan Risk Manager. Profil ini menghasilkan stance BUY/HOLD/SELL dengan mempertimbangkan loss aversion dan horizon waktu.

8. Aturan Wajib Proyek

  • Hanya 3 target makro terkunci yang dipakai dalam universe (XAU, RATE_UST, SPX)
  • Hari tanpa berita = NULL, bukan 0
  • Anti-lookahead bias harus diperhatikan
  • Allocation portfolio harus selalu total 100%
  • Semua output harus jelas dan dapat ditelusuri (explainable)
  • Semua output wajib mencantumkan disclaimer: “Bukan nasihat investasi”
  • Semua model utama tidak boleh bergantung pada LLM runtime

10. Kesimpulan

ARCAS adalah proyek yang ambisius dan terstruktur. Ia bukan sekadar sistem NLP, melainkan ecosystem analisis sentimen market yang menghubungkan teks berita dengan alat analisis ekonomi, portofolio, dan risiko pasar.

Kelebihan proyek ini adalah kejelasan domain, kontrak data yang kuat, dokumentasi yang matang, dan arsitektur yang konsisten. Tantangan utamanya adalah integrasi end-to-end, validasi data real, dan penyelesaian pipeline antar modul.
